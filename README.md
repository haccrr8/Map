**AETHERIS** is a production-ready, Hollywood-grade interactive 3D Globe and Spatial Map Web Application built using Three.js, WebGL, CSS Glassmorphism, and the Web Audio API.

---

## ✨ Features

- **Cinematic WebGL Rendering**: High-performance Earth rendering with procedural cloud meshes, atmospheric Rayleigh scattering, and dynamic starfields.
- **Orbital Telemetry**: Live tracking visualizations for LEO/GEO satellites, commercial air traffic routes, and cyber threat vector lasers.
- **Procedural Sound Engine**: Integrated Web Audio API synth generating realistic sci-fi UI sound effects and target locking cues.
- **Compressed State Sharing**: Real-time URL serialization using `LZ-String` compression for instant bookmarking and view-state sharing with dynamic QR code generation.
- **P2P Spatial Sync**: Built-in WebRTC architecture for multi-user peer-to-peer telemetry broadcasting.
- **Dynamic Cyberpunk HUD**: Glassmorphic UI overlays, reactive HUD themes (Cyberpunk, Military, Matrix), and custom crosshair target locking.

---

## 🛠️ Tech Stack

- **Frontend Core**: HTML5, CSS3 (Glassmorphism & Neon FX), Vanilla JavaScript (ES6+)
- **3D Engine**: [Three.js](https://threejs.org/) (r128) with `OrbitControls`
- **Compression**: [LZ-String](https://github.com/pieroxy/lz-string)
- **Utilities**: [QRCode.js](https://github.com/davidshimjs/qrcodejs)
